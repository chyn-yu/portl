连接 GitHub 仓库

使用只授权 lindaprice-wq/port 的访问令牌。

首次使用：怎样创建令牌？
  1. 点击创建 GitHub 令牌 ↗，登录你的 GitHub 账号。
  2. 在 Repository access 选择 Only select repositories，然后选择 port。
  3. 在 Repository permissions 中，将 Contents 设置为 Read and write；其余保持默认。
  4. 选择合适的有效期，点击 Generate token，然后将令牌粘贴到下方连接。

令牌仅用于向 GitHub 验证仓库写入权限，不保存在浏览器或网站文件中；刷新后需要重新连接。不要把它发到聊天中。

未连接时也可以编辑和预览；连接后才能发布。
